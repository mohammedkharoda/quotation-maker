# Al-Hutaib Quotation Maker

Desktop app for Al-Hutaib Trading & Contracting W.L.L.: turns customer material lists
(photos, PDF, Excel) into quotations, saved as PDF or Excel, and shares them on WhatsApp.

## Download

**[Download QuotationMaker-Setup.exe](https://github.com/mohammedkharoda/quotation-maker/releases/latest/download/QuotationMaker-Setup.exe)**
(always the latest version)

1. Run the downloaded `QuotationMaker-Setup.exe`.
2. If Windows says *"Windows protected your PC"*, click **More info → Run anyway**.
3. Open **Quotation Maker** from the desktop or the Start menu.

Needs Windows 10 or 11 (64-bit) and Microsoft Excel (for PDF, printing and the watermark).

## Updates

Installed copies update themselves. When a new version is out, an **Update to x.y** button
appears at the top of the app. Click it, or just close the app and the update installs.

All versions: [Releases](https://github.com/mohammedkharoda/quotation-maker/releases)
